# 布料活动范围与自有碰撞体

用于引入布料后裙摆或长发被顶起、静止穿背、离身体过远、后颈外折等返修。先分辨源造型、蒙皮参考、活动范围和碰撞体分别造成的影响。字段含义参照[官方布料文档](https://moddocs.bannerlord.com/editor/resource-editors/cloth_simulation/)，读写格式按当前游戏、XML 和工具源码核实。

## 活动距离与自然下垂

顶点 Alpha 定义相对蒙皮位置的最大活动距离，实际范围还受 mesh multiplier 影响；0 固定。布料顶点仍有蒙皮参考位置，开启模拟不会解除这个范围，也不会消除错误的参考造型。检查 Alpha 的量化值、单位和 multiplier，避免把 byte 值直接当米。

根部固定，向悬垂部分平滑增加活动空间；结合实际长度、锚点、拉伸、弯曲和阻尼选择范围。活动距离过小会把长发锁在向外伸出的蒙皮形状，重力也无法让它自然下落。范围过大又可能增加摆动和碰撞难度，不能把增大 Alpha 当成万能修复。固定根部在源数据与求解数据中都应可追踪。

用户允许不影响观感的轻微交叉时，以自然轮廓和动作观感为目标。不要为了把每个采样点的穿透数清零，外移整片长发、膨胀整条裙子或冻结原本应悬垂的部分。

## 拟合与覆盖

- 按需要阻挡布料的实际表面拟合，确认单位、前后轴、骨架和蒙皮姿态：裙摆应覆盖源身体，长发可参考外层衣服轮廓。标准 `human_body` 不能假定适合所有模型；尺寸或覆盖不合适时可能顶起布料，也可能漏掉后背。保留参考样本，不将一次不匹配概括为标准碰撞体必然有问题。
- 自有胶囊按需要覆盖腿、上背或腰背。核对实际 MetaMesh 的碰撞体引用；头发与裙子可分别引用各自适合的配置，修头发时保留已获反馈的裙子碰撞体。
- 胶囊每个端点最多使用两个骨骼影响并归一化，按当前 skeleton/XML 的索引与坐标约定计算随动。端点权重从对应解剖高度和实际身体权重推导，不能复用其他模型编号。
- 检查整组胶囊的并集，包括接缝、端帽和动作后的覆盖。中心线贴合不代表表面贴合；适度重叠避免漏缝，过大的重叠球面可能把颈部或前侧发束顶开。上背覆盖与上端半径应一起调整，不能只扩大最高胶囊。
- 站立也露出臀部时，先检查源身体的腰臀连接、臀部凸面和大腿根是否落在胶囊并集内。采样包含身体三角面内部，不能只看顶点或胶囊中心线；分别报告身体外露与布料间距，不以允许身体外露的正容差判定覆盖通过。余量按当前身体和裙子间隙选择，同时检查是否把裙子顶起，不靠膨胀整条裙子修复。
- 缩小腿部碰撞后静态露出安全裤时，检查整件应遮挡安全裤的高度范围与胶囊并集，尤其是胶囊上端/端帽、两腿之间和腰臀过渡。只在各胶囊原有拟合带内得到“样本全覆盖”，不能证明拟合带之外也被保护。按暴露区域补覆盖或恢复局部余量，同时回归固定裙根和站立轮廓；不要仅以半径比旧版更小作为通过条件。
- 同时检查绑定姿态和原生待机、跑步、持弓、骑乘姿态。碰撞位置要随端点骨骼变换，不能用静态胶囊代表整段动作。

## 约束冲突与局部造型

碰撞要求顶点移到外侧，而活动距离、锚点、拉伸或弯曲又可能不允许该位置。分别报告初始穿透、碰撞修正所需距离、活动上限、残余穿透和固定根部漂移。固定根部不能通过碰撞投影偷偷移动；应调整合理的根部位置或附近碰撞覆盖。仅做不受活动范围限制的投影会产生虚假的“无穿模”结果。

后颈先向外折再下垂时，检查源造型过渡、头颈随动和碰撞端帽。局部修形按高度及前后位置平滑淡入淡出，保留发束层次、固定头皮与无关下段；逐顶点追随最近衣服三角形容易形成波纹。下段蒙皮参考也应按解剖高度连续过渡。

若涉及头部前倾或颈部折叠，脸、眼、头饰、发根需要一致变换，颈部共享边界需比较最终量化权重。降低头骨随动比例是模型专用选择，不是通用头颈修复参数。

## 通用制作与分层验收

流程可以复用，半径、固定区、活动距离和容差按模型测量，不复制已接受案例的数值。先建立源形状、绑定方向和蒙皮正确的基线，再启用布料；错误的绑定姿态不能靠碰撞或增加 Alpha 掩盖。

1. **定义保护面与允许变化**：明确裙片、固定腰带、应遮挡的身体/安全裤和可摆动边界，保留源坐标与权重基线。身体采样覆盖完整保护区域，含三角面内部和胶囊端帽/接缝，不只覆盖原有胶囊拟合带。
2. **联合拟合**：同时衡量身体外露、布料参考面穿透、固定根部受顶和活动距离不足。碰撞体应覆盖保护面，并尽量贴近身体；缩半径通过不等于整体通过，增半径覆盖通过也不等于裙子不会被顶起。新增腰臀碰撞时按实际随动检查骨骼端点权重。
3. **最终包结构检查**：按每个启用 LOD 回读拓扑、Alpha 单位/multiplier、固定点、距离/弯曲约束、映射、碰撞体引用及原生预处理数据。源数据更改后重做预处理；标记存在、反序列化成功和引擎实际动态效果分别报告。
4. **姿态与约束筛查**：至少检查静态站立、完整待机/跑步周期、持武器、抬腿、持弓及骑乘；待机片段从当前动作集解析实际 AnimationClip/GUID。按随动后的身体和胶囊并集检查覆盖，按最终 Alpha 检查活动余量，单独报告固定根部冲突。输出姿态、LOD、最差帧及一致镜头近景；抽帧检查明确记录采样密度，不能称作完整周期检查。
5. **连续动态与游戏验收**：CPU 连续重力/惯性代理可定位抖动或约束冲突，但不是游戏求解器。游戏验收按静止沉降→起步/停止→转向/抬腿→战斗/骑乘→远近 LOD 切换进行，检查露出、顶起、回弹、抖动、换装/预览重建。用户测试时记录版本与入口；未运行引擎的报告保留“游戏动态未验证”。

交付门槛是结构通过、保护面覆盖与固定根/活动范围没有不可接受的冲突、最差帧轮廓检查通过，再等待相应游戏验收。身体覆盖容差和布料轻微穿透容差分开；采样命中率不代表全表面覆盖。此流程能提前拦截常见返工原因，不能承诺零返工。共用结构编译/检查器与模型专用拟合参数分开维护，不把胶囊数量、毫米容差或某套裙子的骨骼编号写成通用默认值。

## 数据与证据

源几何、蒙皮或 Alpha 改变后，重新生成受影响的布料位置、距离、锚点、约束和渲染映射；每个启用 LOD 使用自己的数据。求解固定点与渲染 Alpha 的差异只能来自已记录的显式固定策略。保存 Blend/FBX，回读最终 TPAC 并检查非目标网格和已接受布料保持基线。序列化细节见[离线编译](offline-cloth.md)。

完整蒙皮周期用于筛查参考造型；静态姿态的 CPU 重力、胶囊投影用于定位约束冲突，两者都没有运行游戏求解器，也不覆盖连续动画惯性、所有碰撞模式或体型。报告采样方式、姿态、LOD 和最差帧，顶点/质心/边采样的穿透比例不是全表面可见穿模比例。使用一致镜头检查颈部侧面、背面及最差动作，游戏反馈按实际版本与用户说明范围记录。

## 明玉案例（2026-10-10）

ShengxiuCollection v1.1.7 的后发采用平滑衣服轮廓拟合、局部后颈修形和自有背部胶囊，用户确认头发整体效果可接受，此前裙子也已确认。原 8mm 活动上限限制了下垂；本版发尾最大 200mm、弯曲刚度 0.18、28 个背部胶囊、后颈最多收回 45mm，均为该模型参数，不是新模型默认值。允许轻微穿模是本次用户明确的观感取舍，不推断所有动作或其他套装通过。

实现与证据位于 `D:/gpt-mb2-mod2/mods/ShengxiuCollection/`：`tools/fit_back_hair_source.py`、`tools/fit_free_hair_collision.py`、`reports/back_hair_validation.json`、`reports/free_hair_diagnostic.json`；当前使用说明以该项目 README.md 为准。
